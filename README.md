\# Portfólio de Engenharia de Dados, Estatística e IA



Este repositório reúne meus projetos práticos focados no desenvolvimento de soluções corporativas, inteligência de negócios (BI), automações e monitoramento de infraestrutura de inteligência artificial utilizando Python estruturado.



\## 📁 Estrutura do Repositório



O ecossistema está dividido em três grandes subpastas temáticas:



\### 1. Automações e Motores de Decisão

\* \*\*Foco:\*\* Soluções corporativas e triagem lógica baseada em regras de negócio.

\* \*\*Aplicações:\*\* Sistemas de filtragem automatizada de candidatos, motores paramétricos para análise de risco/score de crédito e classificadores lógicos de leads corporativos.



\### 2. Analytics de Vendas e Performance

\* \*\*Foco:\*\* Análise de dados descritiva, inteligência de negócios e métricas operacionais.

\* \*\*Aplicações:\*\* Análise estatística de faturamento empresarial, somadores de performance de vendas e motores de controle de qualidade industrial com cálculo de desvio percentual em relação a linhas de base (\*baselines\*).



\### 3. Monitoramento de Hardware e NLP

\* \*\*Foco:\*\* Operações de IA (MLOps), processamento de texto e análise preditiva.

\* \*\*Aplicações:\*\* 

&#x20; \* \*\*Monitoramento Contínuo:\*\* Sistema em tempo real utilizando laços de repetição contínuos para análise de estabilidade térmica de chips de IA.

&#x20; \* \*\*Cálculo Aplicado:\*\* Uso de taxa de variação temporal (aproximação de Derivada Discreta) para detecção preditiva de anomalias de calor antes do colapso do hardware.

&#x20; \* \*\*Estatística Aplicada:\*\* Implementação de Média Móvel para suavização de ruídos em streams de dados de sensores.

&#x20; \* \*\*Processamento de Linguagem Natural (NLP):\*\* Scripts para tratamento, higienização de strings corporativas (e-mails/estados) e motores de contagem/verificação de termos textuais.



\## 🛠️ Tecnologias e Conceitos Utilizados

\* \*\*Lógica e Estrutura:\*\* Python 3 (Laços de repetição avançados, funções e estruturas condicionais paramétricas).

\* \*\*Estatística:\*\* Média Móvel, Análise de Dispersão e Desvio Relativo.

\* \*\*Cálculo:\*\* Taxa de variação discreta temporal ($dT/dt$).
